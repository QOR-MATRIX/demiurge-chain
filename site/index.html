An operating system · in development

QOR OS

Play, make and publish on one machine.

An operating system for players, game makers and creators: one account, one library, and the tools to build games, apps, themes and media, driven by a controller as well as a keyboard. Built on Demiurge's network: QOR ID, DRC-369 and CGT.

I · The system

One system, from compositor to arcade

Every part is built to work with the others, and every app shares one look.

Built

Prism

The shell is the compositor: windows and games are live parts of one scene, so any of them can be animated, tiled or set in 3D space. QQ, ARQADE and QOR Media now run inside it.

Built

Lumen

The design language: physically inspired materials, spring motion, continuous curves and perceptual colour, shared by every app.

Built

QQ, the QOR Engine

QQ Studio builds lit 3D and pixel-perfect 2D games with physics, logic, sound and animation, and the QQ Player plays them.

Inside Prism

ARQADE and QOR Media

The arcade, and a player, viewer and editor for video, music, pictures and documents, built in and running inside Prism.

Built

Controllers

QOR OS's own controller service: the common console pads, over USB and Bluetooth, in one layout. It drives the whole shell, and every QQ game.

First stage built

The Store

Games, apps, themes and widgets as signed packages, installed and updated by the system.

Designed

The vault

Keys live in a service of their own, outside the shell and every app. Its approvals are drawn by the compositor, so no app can fake them.

Built

The QOR core

The network's own code for keys, profiles, amounts and the chain, built into QOR OS from Demiurge's open repository rather than written twice.

Swipe for more

QOR OS 1.0 moves no money: free items and test CGT on the devnet only. There is no image to install yet, and its code is private while it is built.

II · Inside Prism

A shell that moves like one thing

Prism draws the desktop and every window in one scene, on springs rather than timers, and draws nothing while nothing changes. This is what it does today.

  • Beam

    One search for apps, actions, settings and files, ranked as you type, with a calculator in it.

  • The Rail

    Glass across the top: the window in front, what is playing in a live capsule, and the state of the machine.

  • The Shelf

    The apps along the bottom, swelling under the pointer, with a mark for each one running.

  • Control Center

    Wi-Fi, Bluetooth, Focus, light or dark, Night Light, brightness, volume, what is playing and the accent.

  • Windows

    Prism's own apps and other Linux apps built for Wayland, in the same frame: each opens at its own size, snaps to halves and flies to the Shelf.

  • Spaces and Overview

    Three Spaces side by side, and every window of one at a glance, live, to pick or carry to another.

  • The controller interface

    A cursor, a focus to move, an on-screen keyboard and the right glyphs for the pad in your hands. A game in front has the pad to itself.

  • Themes and widgets

    An accent, a tint for every surface and a living wallpaper, with widgets on glass over it, from the Store.

  • Several displays

    A window carried from one screen to the next, with Spaces and Overview across them all.

  • Gestures

    Three fingers on a touchpad or a touchscreen switch Spaces and open Overview, following the fingers.

  • Notifications

    Banners that wait while you read them, kept quiet in Focus, with the latest on the lock screen.

  • Its own apps

    Files, Music, Notes, Terminal, Monitor, Settings and the Store, in Lumen from end to end.

III · Where it stands

Shown working, stage by stage

Each stage ends when it is shown working, not on a date.

  1. Phase 0 · done

    Foundations

    Prism, Lumen and the shell, running nested on Linux with real applications, a controller and sound; the Store's first stage; QQ, ARQADE and QOR Media built and tested on Linux.

  2. Phase 1 · now

    One stack

    QQ, ARQADE and QOR Media running inside Prism, driven by a controller.

    • QQ, ARQADE and QOR Media are developed inside QOR OS
    • Prism starts all three, lays out their windows and names them
    • Every window opens at the size its app asks for
    • QQ plays with QOR OS's controllers, and a game in front has the pad
    • ARQADE and QOR Media moved through with a controller's focus
    • Lumen's look on every app
    • A Home and a Library made for the controller

    Its goal: Orb Run, a QQ game, playing inside Prism on Linux with a controller.

  3. Phase 2 · next

    Identity and keys

    One sign-in, chat, and publishing from QQ Studio to the devnet, with the vault built.

  4. Phase 3

    Boots and plays

    It boots on its own, and plays the PC games people already own.

  5. Phase 4

    The ecosystem

    Outside developers ship QQ games to QOR OS with public tools.

VI · Beneath it

Demiurge, the network beneath

A Substrate layer 1 on the Polkadot SDK that pays creators when their work is used, licensed or remixed. QOR OS talks to it as services, and every product shares its four primitives, so nothing invents its own identity, asset format or payment rail.

QOR ID

One identity: a name, a key, levels and an avatar, used by every product, and by other apps through OAuth 2.1.

DRC-369

One asset format: a creator's work pinned by fingerprint, with royalties, remix royalties and nesting enforced on chain.

CGT

One currency, for spending: 1 CGT is 1,000 Sparks, the unit you see and are rewarded in, and every flow of value in the system settles in it.

Qontrol

Version control for people who make things: git underneath, a creator's view on top, and a commit that can be minted as an asset.

Swipe for more

Also on the network: the Mesh, launchers that hold and serve each other's published work. Planned: GNOSIS for music production, Stream for music distribution and licensing over the Mesh, and a fuller Market. The network's roadmap is DIRECTION.md.

VII · The law

Principles

I

Paid for use, not for holding

Validators are paid for securing the chain, seeders for storing and serving, and creators when their work is used, licensed or remixed.

II

Only the vault signs

No app, website or engine holds a key. Every signature is approved in a dialog the system draws itself, which a page or an app can neither draw nor answer: the launcher's today, QOR OS's compositor next.

III

The code is the truth

Documents are checked against the code, every decision is a dated record, and nothing is called done without evidence from a run.

VIII · Asked often

Questions

What is QOR OS?

An operating system for players, game makers and creators, being built on Linux: the Prism shell, which is also the compositor; the Lumen design language; and QQ, ARQADE and QOR Media running inside it. It uses Demiurge's network as services: QOR ID to sign in, DRC-369 for what you own, and CGT.

Can I install QOR OS?

Not yet: there is no image to install while it is built, and it boots on its own only in Phase 3. QOR OS 1.0 moves no money, with free items and test CGT on the devnet only.

What can I use today?

Demiurge's network, on test value. Install the QOR Launcher for Windows, and it makes your wallet and signs you in to QOR ID; ARQADE also plays in a browser; and QOR Mobile previews the launcher on Android. Test CGT has no value, and for now it is sent to testers by hand: there is no faucet page yet.

What does QOR Mobile do yet?

It is the first build of the QOR Launcher for Android: the same Rust core as the Windows launcher, running on the phone and answering through its own screen. The wallet arrives once the phone's keystore holds its key; QOR ID, Social, ARQADE, the Library and the Mesh follow. Installing a newer build over it keeps your phone's copy current, since every build is signed with the same key.

Which controllers work?

The common console pads, wired or over Bluetooth, and any pad Linux knows as one, each shown with its own button glyphs. The whole shell can be driven with one, and QQ's games read it too: whichever game is in front has it.

What is Demiurge?

A Substrate layer 1 built on the Polkadot SDK, and the products on it: the QOR Launcher, QOR ID, ARQADE, the Mesh and QQ. Its standard pieces (consensus, finality, networking, upgrades) are the SDK's own; its own pallets carry DRC-369 assets, royalties, game payouts and the Mesh.

What is CGT?

The Creator God Token, the currency every flow of value settles in. 1 CGT is 1,000 Sparks, and underneath it has 18 decimals: every amount is a whole number of embers, its smallest unit. Its design rests on one rule from the economic model: every mechanic must make sense even if CGT could never be traded for dollars, because people hold it to do things they already want to do.

Where is the code?

The network's code, the launchers' included, is at github.com/QOR-MATRIX/demiurge-chain, under Apache-2.0. It is the only current repository: earlier copies of the project describe a design it no longer follows. QOR OS's code is private while it is built.
